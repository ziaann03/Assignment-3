# PeopleDesk

Clean blue dashboard with a compact employee table.

## Run
1. Extract this ZIP.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Required features
- Home route fetches users from https://jsonplaceholder.typicode.com/users.
- Dashboard displays ID, name, and email in a table.
- Employee Form route contains Name, Designation, Location, and Salary fields.
- React Router navigation links connect Home and Employee Form.
- Bootstrap is included for layout and form styling.

This is a frontend-only assignment. Form submission displays a demo confirmation; it does not require MongoDB or a backend.
